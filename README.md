## Sobre mí

Actualmente estoy formándome en **Tecnología en Desarrollo de Sistemas Informáticos** y, en paralelo, construyendo experiencia mediante proyectos académicos y laborales.

Aprendo haciendo: a medida que avanzo he trabajado con distintas partes del desarrollo — interfaces, lógica de programación, bases de datos, servicios, APIs y aplicaciones en diferentes entornos. Me interesa especialmente entender cómo se organizan los datos y darle a cada proyecto una estructura clara, no solo que funcione.
